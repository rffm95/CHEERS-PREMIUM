# CHEERS O BAR — Menu QR

Menu estático para GitHub Pages. Português/inglês, pesquisa, categorias, destaques, imagens locais e layout para telemóvel.

## Publicação
O workflow .github/workflows/deploy.yml publica automaticamente cada atualização da branch main no GitHub Pages já configurado neste repositório. O ficheiro index.html está na raiz e não requer compilação nem instalação de dependências. Todos os caminhos dos recursos são relativos, compatíveis com /CHEERS-PREMIUM/.

## Atualizar produtos
Editar menu.json: nome e descrição em pt/en, price numérico em euros e category. As imagens vivem em images/.

97 produtos. Alterações de vinhos e Macallan incluídas. 29 imagens novas e 7 imagens fornecidas pelo proprietário. Imagens ilustrativas identificadas; sem reconstrução do interior do bar. A geração foi interrompida por limite de utilização: image-status.json lista os produtos com imagens pendentes. Esses produtos continuam disponíveis sem referências partidas.

O site não envia pedidos nem processa pagamentos; os clientes pedem à equipa.
